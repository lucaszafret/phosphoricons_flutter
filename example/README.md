# phosphoricons_flutter example

A small app showing the six Phosphor styles, Duotone, `shadows` and the `PhosphorIcons` shortcuts.

The folder only contains `lib/` (platform folders are not versioned). To run it:

```bash
cd example
flutter create . --platforms=android,ios,web,linux,macos,windows   # once, pick the ones you need
flutter run
```

[PT] Um app pequeno com os seis estilos do Phosphor, Duotone, `shadows` e os atalhos de `PhosphorIcons`. A pasta só tem `lib/` (as pastas de plataforma não são versionadas): rode `flutter create .` uma vez dentro de `example/` e depois `flutter run`.
